# 데이터 및 개인정보 정책

## Git에 포함하지 않는 것

- 원본/bulk 데이터
- staging/processed 전국 데이터
- 로그
- 인증키와 credential
- 비공개 prompt/task 파일
- 로컬 AI/agent 지침
- 검토 전 개인정보·연락처 필드

실데이터는 기본적으로 저장소 내부의 Git-ignored `data/local/`에서 다룹니다. `KBL_DATA_ROOT`로 위치를 바꿀 수 있지만, 저장소 내부 경로를 쓰는 경우 `data/local/` 하위만 허용합니다.

## 공개 접근과 재배포

공공데이터포털에서 접근할 수 있다는 사실과 Kaggle에 원자료를 재배포할 수 있다는 결론은 분리합니다. 공공데이터포털 이용정책은 제3자 권리가 포함된 경우 정당한 이용허락 확보 필요성을 명시합니다. 따라서 v1의 `이용허락범위 제한 없음` 라벨은 기록하되 Kaggle 재배포 gate는 `UNRESOLVED`로 둡니다.

## 개인정보

사업장명과 소재지주소는 upstream 설명에서 공개 필드로 확인되지만, 이 프로젝트의 전국 단위 재배포에 적합한지는 별도 검토합니다. public build는 향후 명시적 allowlist 방식으로만 생성합니다.
