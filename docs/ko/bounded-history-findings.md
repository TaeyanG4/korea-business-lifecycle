# Bounded History Audit 결과

> 후속 표본 확장 audit이 완료되었습니다. 최신 범위 결론은 [5개 자치단체 History 표본 확장 결과](expanded-history-findings.md)를 참조하십시오.

확인일: **2026-09-07**

이번 audit은 전국 history 수집이 아닙니다. `개방자치단체코드=3000000` 한 곳에 대해 `2026-01-01`과 `2026-09-06` 두 시점만 비교했습니다. 일반음식점, 휴게음식점, 제과점영업 세 카테고리를 동일한 방식으로 검사했습니다.

## 결론

세 카테고리 모두 이번 bounded pair에서는 `MNG_NO_CONTINUITY=STRONG`, `LIFECYCLE_SIGNAL=USABLE_FOR_FURTHER_AUDIT`로 판정했습니다.

이 판정은 다음 정확한 조건에만 근거합니다.

- 두 snapshot 내부 `MNG_NO` 중복 0건
- 시작 시점 `MNG_NO` 소실 0건
- 공통 `MNG_NO`의 인허가일자 변경 0건
- 관찰된 상태 변경은 모두 같은 행의 폐업일자 변경과 함께 발생
- 상태 변경 없는 폐업일자 변경 0건
- 이 bounded pair에서 `03→01` 전이 0건

이는 `MNG_NO`가 공식 PK라는 뜻도, 지속적인 사업체 identity라는 뜻도 아닙니다.

## 추가 주의점

- 휴게음식점 종료 snapshot에는 시작 snapshot에 없던 상태코드 `05`가 1건 관찰됐습니다. 의미를 확인하기 전에는 canonical lifecycle state에 매핑하지 않습니다.
- 사업장명+주소+좌표가 동시에 변경된 공통 `MNG_NO`가 휴게음식점 2건, 일반음식점 7건 있었습니다. relocation, 정정, entity replacement 또는 identifier reuse 가능성을 후속 표본감사에서 확인해야 합니다.
- 두 시점 사이에 `03→01` 전이가 없었다고 해서 reopening이 존재하지 않는다고 결론 내릴 수 없습니다. 중간 상태를 보지 못하는 as-of snapshot 비교이기 때문입니다.
