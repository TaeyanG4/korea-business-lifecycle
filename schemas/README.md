# Canonical schemas

Machine-readable internal canonical contracts live here. They define processing structure, not public-release permission.

- `permit_parent.v1.json`: frozen Food-Service v1 `PERMIT` parent schema.
- `permit_status_episode.v1.json`: frozen Food-Service v1 `PERMIT_STATUS_EPISODE` lifecycle contract. It preserves source status and censoring semantics; production reconstruction remains disabled.

Both v1 canonical contracts are frozen. Schema freeze does not grant public row-level release permission.
